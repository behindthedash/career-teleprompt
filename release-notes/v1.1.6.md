## Hearsay v1.1.6

### Fixed

- Self-heals incomplete faster-whisper model caches instead of repeatedly failing on missing files such as `model.bin`.
- Validates that a cached model contains the actual CTranslate2 model payload before reporting it as downloaded.
- Removes only the affected model cache beneath Hearsay's own model directory and retries the model download/load once.
- Refuses to delete model paths outside Hearsay's managed cache.

### Diagnostics

This release is intended to unblock the built-in **Transcription Performance Test** when an interrupted or partial model download exists. You should no longer need to manually delete Hearsay's model cache to recover from that condition.

### Installer

`HearsaySetup.exe` is attached to this release for a normal Windows upgrade/install.
