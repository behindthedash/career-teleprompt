# Hearsay v1.1.9

## Self-service NVIDIA GPU support

Hearsay no longer expects Windows users to install CUDA/cuDNN developer components manually before using the GPU path.

- Adds **Install GPU Support (~1.3 GB)** to the NVIDIA card in **Settings → Performance Test...**.
- Downloads official NVIDIA Windows `nvidia-cublas-cu12` and `nvidia-cudnn-cu12` wheels directly from PyPI only after the user opts in.
- Pins package versions and SHA-256 digests and rejects unexpected download hosts or corrupted payloads.
- Extracts the runtime DLLs and included license files into `%LOCALAPPDATA%\Hearsay\gpu-runtime` without changing the machine-wide `PATH`.
- Activates the Hearsay-managed DLL directory for normal CUDA transcription and isolated GPU preflight child processes.
- Supports cancellation and cleans partial staging data after failed or cancelled installs.
- Keeps the normal Hearsay installer small; NVIDIA's large proprietary runtime remains an optional download.

## First-run reliability

- The setup wizard now explains the optional GPU-runtime download when it recommends NVIDIA acceleration.
- GPU runtime setup happens before the Whisper model is prepared.
- If optional GPU support cannot be installed, setup falls back to the supported CPU `small.en/int8` configuration instead of saving a CUDA configuration that cannot run.

## Diagnostics

Missing cuBLAS/cuDNN preflight errors now direct users to Hearsay's **Install GPU Support** action instead of asking them to install CUDA libraries manually.

The representative NVIDIA GPU performance sample remains pending until a packaged Hearsay build completes at least three minutes of effective audio after a successful CUDA preflight.
