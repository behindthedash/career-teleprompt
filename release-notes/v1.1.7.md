# Hearsay v1.1.7

## Fixed

- Avoid Windows `WinError 448` / "untrusted mount point" failures when loading faster-whisper models from Hugging Face snapshot caches.
- Materialize each Whisper model into Hearsay-owned flat local storage before CTranslate2 loads it, so inference does not depend on Hugging Face snapshot reparse points or symlinks.
- Download into a temporary staging directory and promote the model only after required CTranslate2 files are present.
- Repair inaccessible or incomplete materialized model files once automatically, without following or deleting arbitrary paths from error messages.
- Add regression coverage for the exact Windows untrusted-mount-point failure observed during Transcription Performance diagnostics.

## Diagnostics

After upgrading, the first CPU and GPU diagnostics run may download `small.en` and `turbo` again into the new Windows-safe local model storage. Existing legacy Hugging Face cache directories are ignored rather than used for inference.
