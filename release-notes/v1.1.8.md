# Hearsay v1.1.8

## Fixed

- GPU performance tests now run a real CUDA inference preflight in an isolated child process before live capture starts.
- Systems where the GPU is visible but required CUDA inference libraries are unavailable now get an actionable failure instead of freezing at the first 4-second window.
- GPU preflight is bounded and cancellable; a hung preflight process is terminated safely.
- Diagnostics no longer drain queued audio after cancellation.
- Transcription inference errors are surfaced to diagnostics instead of being counted as successful performance observations.
- If an in-process native inference call refuses to stop, the diagnostics UI recovers after a bounded wait and requires restarting Hearsay before another test instead of remaining locked.
- The diagnostics runner no longer unloads a model object that may still be in use by an abandoned native worker.

## GPU runtime note

On Windows, faster-whisper/CTranslate2 GPU inference requires NVIDIA cuBLAS for CUDA 12 and cuDNN 9. Hearsay now checks actual inference readiness before starting the live GPU benchmark and reports missing or incompatible runtime libraries directly.
